Types#

Core protocol data models shared by the pairing and sign layers.

Inbound models (anything a wallet sends us) ignore unknown fields so that newer wallets keep working; outbound serialization should use WalletConnectModel.to_json().

class walletconnect.types.Metadata(*, name: str, description: str = '', url: str = '', icons: list[str] = <factory>, redirect: ~walletconnect.types.Redirect | None = None)#

Bases: WalletConnectModel

App or wallet metadata shown to the other peer.

For a dApp, wallets display this on the connection and signing prompts. Most wallets show name and icons; many (MetaMask in particular) show the host of url most prominently, e.g. “Request from example.com”. Set all fields to your own app.

The model is lenient so that metadata received from wallets always parses; SignClient validates the metadata it sends.
