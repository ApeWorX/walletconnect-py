State#

Serializable client state: the relay identity key and settled sessions.

The library never writes state anywhere on its own. Take a snapshot with SignClient.export_state(), store it however you like (file, database, S3, a secrets manager…), and pass it back with SignClient(state=...) to resume the same sessions later.

Warning

A ClientState contains secrets: the relay identity key and each session’s symmetric encryption key. Anyone holding it can read and send messages on those sessions (e.g. ask the wallet to sign). Store it like a password: encrypted at rest, with tight access permissions, and never in logs or source control.

relay_key: str#

Ed25519 seed (hex) for the relay identity (did:key client ID). Secret.

save(path: str | PathLike[str]) → Path#

Atomically write the state as JSON to path with 0600 permissions.

The library has no default location: you choose path. Missing parent directories are created with 0700 permissions.
