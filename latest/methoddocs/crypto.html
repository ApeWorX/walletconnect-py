Crypto#

X25519 / HKDF / ChaCha20-Poly1305 primitives and Ed25519 relay auth.

Decode a did:key:z… issuer string to the raw 32-byte Ed25519 public key.

Split a JWT into header, payload, and raw signature bytes.

walletconnect.crypto.decrypt(*, sym_key: str, encoded: str, encoding: Literal['base64', 'base64url'] = 'base64') → str#

Open a typed envelope and return the UTF-8 plaintext.

walletconnect.crypto.derive_sym_key(private_key_a: str, public_key_b: str) → str#

Derive a 32-byte symmetric key via X25519 + HKDF-SHA256.

Salt defaults to 32 zero bytes and info is empty, matching the JS SDK (hkdf(sha256, shared, undefined, undefined, 32)).

walletconnect.crypto.deserialize(encoded: str, *, encoding: Literal['base64', 'base64url'] = 'base64') → dict[str, bytes | int]#

Split a base64 envelope into type, iv, sealed, and optionally sender_public_key.

walletconnect.crypto.encode_did_key(public_key: bytes | str) → str#

Encode an Ed25519 public key as did:key:z….

public_key may be 32 raw bytes or 64 lowercase hex characters.

walletconnect.crypto.encrypt(*, sym_key: str, message: str | bytes, type: int = 0, sender_public_key: str | None = None, iv: bytes | str | None = None, encoding: Literal['base64', 'base64url'] = 'base64') → str#

Seal message under sym_key and return a typed envelope string.

message is UTF-8 encoded when given as str. iv may be 12 raw bytes or 24 hex characters; a fresh IV is generated when omitted.

walletconnect.crypto.generate_auth_key_pair(seed: bytes | str | None = None) → AuthKeyPair#

Generate (or restore) an Ed25519 auth key pair.

When seed is given (32 bytes or 64 hex chars) the key pair is deterministic, matching ed25519.generateKeyPairFromSeed in the JS SDK.

walletconnect.crypto.generate_key_pair() → KeyPair#

Generate a fresh X25519 key pair.

walletconnect.crypto.generate_random_bytes32() → str#

Return 32 cryptographically random bytes as lowercase hex (a pairing symKey).

walletconnect.crypto.hash_key(key: str) → str#

SHA-256 of a hex-decoded key, returned as lowercase hex (used as a topic).

walletconnect.crypto.serialize(*, type: int, iv: bytes, sealed: bytes, sender_public_key: bytes | None = None, encoding: Literal['base64', 'base64url'] = 'base64') → str#

Serialize a typed envelope to a base64 string.

walletconnect.crypto.sign_jwt(*, aud: str, key_pair: AuthKeyPair, sub: str | None = None, ttl: int = 86400, iat: int | None = None, act: str = 'client_auth') → str#

Build a relay auth did-JWT.

Payload claim order matches the WalletConnect reference implementation: iat, exp, act, iss, sub, aud.

walletconnect.crypto.topic_from_sym_key(sym_key: str) → str#

Return the WalletConnect topic for a symmetric key (sha256(symKey).hex()).

walletconnect.crypto.verify_jwt(jwt: str, *, now: int | None = None) → dict[str, Any]#

Verify an EdDSA did-JWT and return its payload.

Checks the header, recovers the public key from iss, verifies the signature, and rejects expired tokens (when exp is present).
