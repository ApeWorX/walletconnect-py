Terminal QR#

Render pairing URIs as QR codes in a terminal.

Requires the optional qr extra:

pip install "walletconnect[qr]"

Two styles are available:

  • compact=True (default): Unicode half blocks (▀▄█), two QR rows per text line. Small enough for an 80-column terminal and scans well from a screen.

  • compact=False: plain 7-bit ASCII (## / two spaces per module). Safe for logs, CI output, and chat/bot messages that mangle Unicode (use a monospace font/code block).

By default the output is drawn for a dark terminal background (invert=True): the “ink” characters paint the light modules and quiet zone, so the code appears dark-on-light. Pass invert=False for light backgrounds, or when printing on paper.

walletconnect.qr.DEFAULT_BORDER = 2#

Quiet-zone width in modules. The spec suggests 4; 2 is plenty on screens and saves space.

walletconnect.qr.print_qr(data: str | PairingURI, compact: bool = True, invert: bool = True, border: int = 2, file: TextIO | None = None) → None#

Print terminal_qr() output (defaults to sys.stdout).

walletconnect.qr.qr_matrix(data: str | PairingURI, border: int = 2) → list[list[bool]]#

Encode data as a (regular, never Micro) QR code.

Returns:

Rows of modules, True meaning a dark module, including the quiet zone.

walletconnect.qr.render_matrix(matrix: Iterable[Iterable[bool]], compact: bool = True, invert: bool = True) → str#

Render a module matrix (True = dark) as terminal text.

walletconnect.qr.terminal_qr(data: str | PairingURI, compact: bool = True, invert: bool = True, border: int = 2) → str#

Return a printable QR code for data (e.g. a wc: pairing URI).

Parameters:

  • data – The URI (or any string) to encode.

  • compact – Use Unicode half blocks (default) instead of pure ASCII.

  • invert – Draw for a dark terminal background (default).

  • border – Quiet-zone width in modules.
