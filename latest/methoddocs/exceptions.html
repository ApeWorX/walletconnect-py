Exceptions#

Exceptions raised by walletconnect.

Peer (wallet) errors use the WalletConnect SDK error codes: https://specs.walletconnect.com/2.0/specs/clients/sign/error-codes

Bases: WalletConnectError, ValueError

Raised when a CAIP-2 chain ID or CAIP-10 account ID is malformed.

exception walletconnect.exceptions.RelayConnectionError#

Bases: RelayError, ConnectionError

Raised when the relay WebSocket cannot be established or drops unexpectedly.

exception walletconnect.exceptions.RelayDisconnectedError#

Bases: RelayConnectionError

Raised when a relay request cannot complete because the WebSocket dropped.

Relay requests (publish, subscribe, …) are retried transparently after an automatic reconnect; this is raised only when the connection was not restored within the request timeout, when auto-reconnect is disabled, or when the client was closed.

exception walletconnect.exceptions.RelayError#

Bases: WalletConnectError

Raised when the WalletConnect relay returns a JSON-RPC error or protocol fault.

exception walletconnect.exceptions.SdkError(message: str | None = None, data: Any | None = None, code: int | None = None)#

Bases: WalletConnectError

An error returned by the peer as a JSON-RPC error with a WalletConnect SDK error code.

Use SdkError.from_code() to get the most specific subclass for a given code.

classmethod from_code(code: int, message: str | None = None, data: Any | None = None) → SdkError#

Build the most specific SdkError for a JSON-RPC error code.

to_json() → dict[str, Any]#

Serialize as a JSON-RPC error object.
